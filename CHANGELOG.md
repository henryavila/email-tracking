# Changelog

All notable changes to this project are documented in [GitHub Releases](https://github.com/henryavila/email-tracking/releases).

## 7.1.0 - 2026-11-17

- Allow Laravel 13 (`illuminate/contracts` `^11.0|^12.0|^13.0`) without dropping Laravel 11 or 12.
- Allow `spatie/laravel-permission` `^6.0|^7.0|^8.0`. This package does not call that API; the wider range matches applications already on 6, 7, or 8.
- Document PHP 8.5 support. The PHP constraint stays `^8.2`.
- Allow `orchestra/testbench` `^11.0` next to `^9.0|^10.0`.

No public method, class, or schema change.
